Turn everyday things into game controllers.

Wire a real-world object to a micro:bit. Its sensors read how you touch, tilt, or shake it and send that over Bluetooth to this page — where it plays a little game. Flash a starter, connect, and go.

🧸 object → micro:bit → bluetooth → game 🎈

Flash a sensor starter

Each starter reads one kind of micro:bit input and sends it with the little protocol below. Open one in MakeCode, tweak it for your object, and flash it to a micro:bit v2.

✦

The little protocol

Just three kinds of message, one per line. The page only knows these three — so the same visualizer and game work with any sensor you make.

once trigger

A one-off event — a shake, a clap, a click. This is what makes the game jump.

on / off state:true

A held switch — a button pressed down, or an object being touched.

smooth value:0.42

A sliding number from 0 to 1 — tilt, brightness, loudness.

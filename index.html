Wire a real-world object to a BBC micro:bit, and its sensors stream your interactions over Web Bluetooth to this page — turning an everyday fidget object into a controller for a browser game. Flash a starter, connect, and play.

1 Flash a sensor starter

Each starter reads one kind of micro:bit input and streams it using the same simple protocol (below). Open one in MakeCode, tweak it for your object, and flash it to a micro:bit v2.

The input protocol

Every starter speaks the same three-message language over the micro:bit UART service, one message per line. The browser only understands these three abstract types — so the same visualizer and game work with any sensor you build.

trigger

Momentary event. Fires once — a shake, clap, or click. Drives the flap/jump.

state:true

Held on/off. Changes when the input turns on or off — a button held down, or an object being touched.

value:0.42

Continuous. A reading normalized to 0.0–1.0 — tilt, light level, loudness.

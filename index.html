Turn Anything into a Game Controller

Set up your micro:bit

A one-time setup: add Bluetooth to your code in MakeCode, flash a starter, and find your board's Bluetooth name so you can connect to it. About five minutes.

  1. 1

    Grab a micro:bit v2

    You'll need a micro:bit v2 (the microphone and logo-touch inputs are v2-only) and a USB cable. A battery pack is handy once you unplug from the computer.

  2. 2

    Open MakeCode and add Bluetooth

    Go to makecode.microbit.org and start a new project. Open Extensions, search for Bluetooth, and add it. MakeCode will warn that this removes the Radio blocks — that's expected; we don't use radio.

  3. 3

    Turn off pairing

    Click the gear (top-right) → Project Settings. In the Bluetooth section, choose “No Pairing Required: Anyone can connect via Bluetooth.” This lets the browser connect straight away, without first pairing the micro:bit in your computer's Bluetooth settings.

  4. 4

    Flash a starter

    Pick a sensor starter and open it in MakeCode. Plug the micro:bit in over USB, click Download, and drag the downloaded .hex onto the MICROBIT drive (or use MakeCode's Connect device to flash directly). The yellow light blinks while it copies, then stops when it's done.

  5. 5

    Find your micro:bit's name

    Every micro:bit has a unique five-letter Bluetooth name and shows up as BBC micro:bit [zuzet] (five letters of its own). When it powers on, the starter scrolls that five-letter code across the LEDs — note yours so you can spot it in a room full of boards.

  6. 6

    Connect

    Click Connect in the top bar. In the browser's Bluetooth list, pick the BBC micro:bit [·····] that matches your five letters. The status dot turns green and your input shows up in the Live panel (top-right) from any screen.

Sensor starters

Each starter reads one kind of micro:bit input and sends it with the protocol below. Open one in MakeCode, tweak it for your object, and flash it (see the Set up screen).

The protocol

Three kinds of message, one per line. The page only knows these three, so the same visualizer and game work with any sensor you make.

trigger

A one-off event — a shake, a clap, a click. This is what makes the game jump.

state:true

A held switch — a button pressed down, or an object being touched.

value:0.42

A number from 0 to 1 — tilt, brightness, loudness.

Play

Connect your controller in the top bar, then use it here. Right now it's a placeholder — my collaborator is adding Flappy Bird. The bird already flaps on trigger, so you can check your controller works end to end. Watch the raw input any time in the Live panel (top-right).

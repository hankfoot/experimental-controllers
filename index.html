CH.01

Flash a sensor starter

Each starter reads one kind of micro:bit input and streams it with the shared protocol below. Open one in MakeCode, tune it for your object, and flash it to a micro:bit v2.

SPEC

The input protocol

Three message types, one per line, over the micro:bit UART service. The browser only knows these three — so the same visualizer and game work with any sensor you build.

trigger

Momentary event. Fires once — a shake, clap, or click. Drives the flap / jump.

state:true

Held on / off. Flips when the input turns on or off — a button held down, an object being touched.

value:0.42

Continuous. A reading normalized to 0.0–1.0 — tilt, light level, loudness.
